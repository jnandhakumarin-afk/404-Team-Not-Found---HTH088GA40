# Project Logo Asset Location

Place your official project logo in this directory as:
- `logo.png` (or `logo.svg`)

The AI Code Review & Release-Risk Assistant frontend will automatically detect and render the logo in both Dark and Light themes.

Specifications:
- Format: PNG (transparent background recommended) or SVG
- Recommended dimensions: ~200px width x 60px height (or square 128x128px)
- Color safety: Ensure high visibility on both dark (#1A1B25) and light (#F4F6F8) backgrounds.
